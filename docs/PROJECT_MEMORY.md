## 栈与端口

pnpm monorepo（pnpm 9）。需要 Node.js ≥ 22.5（API 使用内置 `node:sqlite`）。

`pnpm dev` 同时拉起四个进程：

| 端 | 端口 | 目录 |
| --- | --- | --- |
| API | 4310 | `apps/api` |
| 商户工作台 | 4311 | `apps/merchant-web` |
| 运营看板 | 4312 | `apps/ops-web` |
| 消费者 | 4313 | `apps/consumer-uniapp` |

共享包：`packages/shared`（模型与文案）、`packages/tryon-viewer`（Three.js 人台与占位服装）。

## 已做

- **商户模拟重建。** 商户补齐正面、侧面、背面后可以发起重建。工人按阶段推进（接收、核对、轮廓、网格、发布），生成的是占位网格，照片像素不参与几何。可以勾选「模拟失败」再重试。适配器目前只有 `stub`（`apps/api/src/reconstruct.ts`）。
- **消费者三个 Tab。** 底部是商城、试衣间、我的。
  - 商城：浏览已发布样衣。「加入试衣间」只记进清单，不结算。
  - 试衣间：同一部位再选一件，会换掉身上那件（上装换上装，下装换下装）。上装和下装可以叠在一起。展开「调整身材」会改参数化人台。
  - 我的：可以新建人员，填写头像、照片、生日、年龄、性别、手机号和身材尺寸。保存后出现在试衣间的选人列表里。照片只存档。
- **HTML 体验板（非正式工程源）。** 另有一份用来点交互的 HTML 体验板，上面有场景背景和预制姿势。它不在本仓库里，不是正式工程源，也还没有接进 API 或消费者端。
